## [1.10.0] - 2026-10-05

### Production API Server Enhancements

#### New Endpoints
- `GET /drama/info_v2?series_id=xxx&scene=1` - Drama detail information
- `POST /search/drama` - Search dramas by keyword (returns `name`/`id` fields)
  - **Limitation:** Pagination NOT supported by upstream API
  - Always returns first 20 results regardless of `offset`, `page`, or `page_size` parameters
  - Tested: offset=0, offset=20, page=2 all return identical 20 items
- `POST /homepage/v2/tab/feed` - Direct proxy endpoint for playground compatibility

#### Tab System Overhaul
- **Breaking:** Replaced `tab_key` with `module_key` for all feed tabs (except 622 Segera Hadir)
- Tab names changed to clean Indonesian labels (removed upstream Chinese campaign names)
- Added 4 ranking tabs: Harian (daily), Mingguan (weekly), Bulanan (monthly), Tahunan (annually)
- Mapping:
  - Populer: `module_key: "1036"`
  - New: `module_key: "1040"`
  - Dubbing: `module_key: "1065"`
  - Perempuan: `module_key: "1039"`
  - Laki-Laki: `module_key: "1041"`
  - Anime: `module_key: "2204"`
  - Segera hadir: `tab_key: "622"` (unchanged, uses `/tab/index`)
  - Ranking tabs: `ranking_id: "daily"|"weekly"|"monthly"|"annually"`

#### Feed Filtering
- Automatic removal of ranking card items (`item_type: "card"`) from `/api/feed` and `/homepage/v2/tab/feed` responses
- Clean drama-only feeds without navigation cards

#### Performance
- Parallel module name fetching removed (eliminated slow upstream requests)
- Session reuse for all client operations
- Response time: instant (no background fetches)

#### Frida Hooks
- `hook_count_all_tabs_v2.js` - Universal drama counter with deduplication
- Auto-detects flat items, nested items, and pagination info
- Tracks session totals per tab/module

#### Configuration
- Default port: 7406
- Server: `http://localhost:7406`

#### Bug Fixes
- Fixed `get_client()` import path (`freereels_client` from `src/`)
- Fixed kategori 622 (Segera hadir) structure: 241 items via `/tab/index` (no pagination)
- Fixed session reuse preventing unlimited pagination exploit

## [1.0.0] - 2026-10-04

### Added
- **Anonymous Login System**: Fully independent guest authentication without phone requirement
  - Auto-generate device_id and OAuth credentials
  - MD5-based signature: `MD5("8IAcbWyCsVhYv82S2eofRqK1DF3nNDAv" + device_id)`
  - OAuth header format: `oauth_signature={sig},oauth_token={token},ts={ts_ms}`
  
- **Response Decryption Engine**: AES-128-CBC automatic decryption
  - Extracted native keys from `libdwguard.so` (ARM64 binary)
  - Flavor 1: `3sa9Kx7mQu3Ls8Wd`
  - Flavor 2: `79psatnvfgktswba`
  - Auto-detect encrypted responses via `x-decry: 1` header
  - Format: `Base64(IV_16 || AES-CBC-ciphertext || PKCS7-padding)`

- **Multi-Language Support (22 Languages)**: Dynamic content localization via HTTP headers
  - Supported: Indonesian, English, Spanish, Portuguese, French, German, Italian, Russian, Arabic, Hindi, Tamil, Telugu, Bengali, Thai, Vietnamese, Filipino, Malay, Japanese, Korean, Traditional Chinese, Polish, Turkish
  - Method: `client.set_language("en")` or `client.set_language("ja-JP")`
  - Headers updated: `app-display-lang`, `language`, `device-language`, `country`, `device-country`
  - Server returns different drama catalogs and titles per language
  - Default language: Indonesian (`id-ID`)

- **API Endpoint Discovery**: 120+ reverse-engineered endpoints mapped
  - Homepage feeds, drama info, search, categories, user profile, bookmarks, history
  - Video URLs extraction from `/drama/info_v2` endpoint
  - Subtitle lists (25 languages) with SRT and VTT formats
  - Episode metadata with HLS streaming URLs

- **Video Extraction System**:
  - HLS master playlist URLs: `external_audio_h264_m3u8` and `external_audio_h265_m3u8`
  - Adaptive bitrate streaming: 240p, 360p, 480p, 540p, 720p
  - Direct CDN access for free episodes (no additional auth)
  - Subtitle tracks in 25 languages (SRT + VTT)

- **Native Library Analysis**:
  - Disassembled `libdwguard.so` (ARM64, 20KB)
  - Extracted AES keys at memory offsets `0x13c0` and `0x13d0`
  - Identified anti-debug mechanisms (TracerPid check, APK signature validation)

- **Documentation**:
  - `docs/ANONYMOUS_LOGIN_SPEC.md`: Anonymous login flow
  - `docs/RESPONSE_DECRYPTION_SPEC.md`: AES decryption specification
  - `docs/API_ENDPOINTS_COMPLETE.md`: 120+ endpoints catalog
  - `docs/LANGUAGE_LOCALIZATION_SYSTEM.md`: Language system architecture
  - `docs/VIDEO_EXTRACTION_GUIDE.md`: HLS video extraction guide
  - `docs/ARCHITECTURE_AND_SECURITY_ANALYSIS.md`: Comprehensive security analysis

- Czech (`cs-CZ`), Romanian (`ro-RO`), Greek (`el-GR`) languages - no content available on server

### Security
- All credentials auto-generated (no hardcoded secrets)
- OAuth tokens refresh per session
- Device fingerprinting isolated per client instance
- Response encryption/decryption transparent to consumer

### Technical Details
**Authentication Flow:**
1. Generate random `device_id` (16-char hex)
2. Calculate `sign = MD5(prefix + device_id)`
3. POST `/anonymous/login` with device_id and sign
4. Server returns `auth_key` (oauth_token) and `auth_secret`
5. All subsequent requests use OAuth signature header

**Language Switching:**
- Updates 5 HTTP headers dynamically
- Server filters catalog by `country` header
- Content titles and descriptions localized per `language` header
- Subtitle tracks available regardless of language setting

**Video Access:**
- Free episodes: HLS URLs directly accessible
- VIP episodes: Server may return empty HLS URL or CDN returns 403
- No separate `/drama/download` endpoint needed
- M3U8 playlists parseable with standard tools

### Known Limitations
- VIP unlock mechanism not fully analyzed (no VIP-locked dramas in test sample)
- Some drama IDs region-specific (may return empty data in different locales)
- Response encryption flavor selection not documented by server

- Python 3.11+

- `capstone`: ARM64 disassembly (for native analysis)
